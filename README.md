# ArtNSculps

A free static starter marketplace for art, press-on nails and clothing.

## Run it
Open `index.html` in a browser.

## Publish it free
Upload these three files (`index.html`, `style.css`, `script.js`) to a public GitHub repository and enable GitHub Pages.

## Important
This version is a front-end prototype. Account data, cart data, listings and demo purchases are stored in the visitor's browser with localStorage. It does not yet provide secure multi-user accounts, real image storage, a server database, or real payment processing. Those require a backend/payment provider.
